One word an agent says when it has no idea what to do: **recalculating**. Not a stall like "buffering" and not the obvious "uh" — it is what a lost agent actually does mid-task, abandoning the plan and re-planning out loud in the flat voice of a machine caught out. It lands instantly, sounds like something an agent would blurt out, and stays fresh because it is a reaction, not a filler.

## Run

```sh
node main.ts
```

Writes the single word to `/output/entry.txt`.
